# Directory Overview

This directory contains an Obsidian vault named "Cyber Spell." Obsidian is a note-taking and knowledge management application that uses Markdown files. The content of this vault is focused on world-building for a "cyber-fantasy" setting, blending elements of science fiction and fantasy.

The purpose of this directory is to store and organize the creative writing and ideas related to the "Cyber Spell" world. It has been structured as a personal wiki or digital garden for the project, with different aspects of the world broken into their own dedicated, interlinked files.

# Key Files

The vault has been organized into a collection of specialized documents to facilitate focused world-building.

*   **`CyberSpell_Start.md`**: The central hub and checklist for the project. It tracks the overall progress of the world-building and provides high-level links to the more detailed lore documents.

*   **`WorldLore.md`**: Contains the foundational history of the Cyber Spell setting.

*   **`Techno Wizardry.md`**: Explains the principles of the world's "magic system."

*   **`The Daemons.md`**: Describes the "monsters" of the setting.

*   **`Faction_BrainStorm.md` & `Faction_Interactions.md`**: These files contain the initial brainstorming for the world's factions and their relationships. They are now largely superseded by the detailed files in the `Factions/` directory.

*   **`Factions/`**: This directory contains the fully defined major factions of the world. Each file details a faction's leaders, core principles, unique facts, and their relationships with other major powers.
    *   `The_Aegis_Corporation.md`
    *   `The_Church_of_the_Omnissiah.md`
    *   `The_Free_Orbital_Alliance.md`
    *   `The_Scrap_Barons_of_Rustholm.md`
    *   `Unit_734.md`

*   **`Locations/`**: This directory contains detailed descriptions of specific places in the world, focusing on smaller-scale, adventure-oriented locations.
    *   `Haven.md`: A well-off frontier city that serves as a potential starting location.
    *   `The_Stuttering_Diode.md`: A tavern and information hub.
    *   `Vault_of_the_Silent_Masters.md`: A hidden sanctuary for Wayfaring Samurai.
    *   `The_Bounty_Board.md`: A decentralized network for jobs and contracts.

*   **`Grand_Locations.md`**: Describes several large-scale, world-shaping locations.

*   **`.obsidian/`**: This directory contains the configuration files for the Obsidian vault. These files are managed by Obsidian and generally do not need to be edited manually.

# Usage

This directory is intended to be used with the Obsidian application. To work with the "Cyber Spell" vault:

1.  Download and install Obsidian from [https://obsidian.md/](https://obsidian.md/).
2.  Open Obsidian and use the "Open folder as vault" option.
3.  Select the `Cyber Spell` directory.

Once the vault is open, you can use the `CyberSpell_Start.md` file as a table of contents to navigate between the different lore documents as you develop the world.
